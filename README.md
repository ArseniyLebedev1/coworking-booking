# Платформа бронирования переговорных и коворкингов

Веб-приложение для поиска и бронирования переговорных комнат и рабочих мест в коворкингах.

## Цель проекта

Разработать платформу, позволяющую сотрудникам бронировать помещения на определённую дату и время без пересечения бронирований.

## Роли пользователей

- Гость — просмотр доступных помещений.
- Сотрудник — бронирование помещений и управление своими бронированиями.
- Администратор — управление помещениями, пользователями и бронированиями.

## Основные возможности

- Регистрация и авторизация пользователей.
- Просмотр доступных помещений.
- Поиск и фильтрация помещений.
- Бронирование по дате и времени.
- Запрет пересекающихся бронирований.
- Просмотр и отмена своих бронирований.
- Панель администратора.

## Технологический стек

- Frontend: React, TypeScript, Vite
- Backend: Python, FastAPI
- Database: PostgreSQL
- ORM: SQLAlchemy
- Database migrations: Alembic
- API documentation: OpenAPI, Swagger UI
- Containerization: Docker, Docker Compose
- CI/CD: GitHub Actions
- Version control: Git, GitHub


## Быстрый запуск

```bash
cp .env.example .env
# Обязательно задайте уникальный JWT_SECRET_KEY в .env
docker compose up --build -d
```

Интерфейс: http://localhost:5173 — API: http://localhost:8000/docs.
