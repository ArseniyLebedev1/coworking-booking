# SpaceBook — презентация к защите

> Рекомендованный формат: 9 слайдов, 5–7 минут. Замените финальный слайд на реальный публичный адрес после развёртывания.

## Слайд 1. Титульный
SpaceBook — платформа бронирования переговорных и коворкингов. Учебная практика, 9 дней / 72 часа.

## Слайд 2. Проблема и цель
Проблема: сложно находить свободные переговорные, вручную согласовывать время, избегать двойных броней.
Цель: веб-платформа с каталогом, бронированием и разграничением прав.

## Слайд 3. Роли и пользовательские сценарии
Гость: каталог и фильтры. Сотрудник: регистрация, вход, бронь, отмена, личный кабинет. Администратор: CRUD помещений, пользователи, изображения, статистика.

## Слайд 4. Архитектура
React + TypeScript + Vite → FastAPI REST → PostgreSQL 16. SQLAlchemy + Alembic. Docker Compose, GitHub Actions. Caddy HTTPS для публичного развёртывания.

## Слайд 5. Данные
7 таблиц: roles, users, locations, rooms, bookings, amenities, room_amenities. Связи 1:N и M:N. EXCLUDE constraint предотвращает пересечение активных бронирований одного помещения.

## Слайд 6. Основные функции
Каталог, поиск, фильтры, пагинация. JWT-авторизация, защита паролей Argon2. Бронирование и история действий. Загрузка фотографий администратором.

## Слайд 7. Демо
Показать каталог → фильтр → карточка помещения → вход → бронирование → кабинет → отмена; администратор → дашборд. Использовать реальные скриншоты приложения.

## Слайд 8. Тесты и качество
GitHub Actions: тесты Python, сборка фронтенда, интеграционные сценарии с PostgreSQL. Показать зелёные проверки и результат защиты от двойной брони.

## Слайд 9. Результаты и перспективы
Учебный MVP реализован локально. Production-инфраструктура подготовлена; публичный адрес потребует VPS и домена. Перспективы: календарь занятости, уведомления, полноценная работа с удобствами, мониторинг и CI/CD-деплой.
