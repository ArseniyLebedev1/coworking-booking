# User Stories

## US-01. Регистрация
Как гость, я хочу зарегистрироваться, чтобы получить доступ к бронированию помещений.

Критерии приёмки:
- Регистрация по email и паролю.
- Проверка корректности данных.
- Пароль хранится в виде хэша.

## US-02. Авторизация
Как сотрудник, я хочу войти в систему, чтобы управлять своими бронированиями.

Критерии приёмки:
- Вход по email и паролю.
- Авторизация через JWT.
- Возможность выхода из системы.

## US-03. Просмотр помещений
Как гость, я хочу просматривать помещения, чтобы выбрать подходящее.

Критерии приёмки:
- Отображается список помещений.
- Видны название, вместимость и описание.

## US-04. Поиск помещений
Как сотрудник, я хочу искать помещения, чтобы быстро находить нужные.

Критерии приёмки:
- Поиск по названию.
- Фильтрация по вместимости.
- Пагинация результатов.

## US-05. Бронирование
Как сотрудник, я хочу бронировать помещение на определённое время, чтобы проводить встречи.

Критерии приёмки:
- Выбор даты и времени.
- Создание бронирования.
- Подтверждение успешного бронирования.

## US-06. Проверка пересечений
Как сотрудник, я хочу видеть занятые временные интервалы, чтобы не бронировать уже занятое помещение.

Критерии приёмки:
- Занятые интервалы отображаются в календаре.
- Сервер запрещает пересекающиеся бронирования.
- При конфликте выводится сообщение об ошибке.

## US-07. История бронирований
Как сотрудник, я хочу просматривать свои бронирования, чтобы отслеживать запланированные встречи.

Критерии приёмки:
- Отображается список собственных бронирований.
- Видны дата, время и помещение.

## US-08. Отмена бронирования
Как сотрудник, я хочу отменять свои бронирования, чтобы освобождать помещение.

Критерии приёмки:
- Можно отменить собственное бронирование.
- Требуется подтверждение отмены.
- Отменённый интервал снова доступен.

## US-09. Управление помещениями
Как администратор, я хочу управлять помещениями, чтобы поддерживать актуальный список.

Критерии приёмки:
- Создание помещения.
- Редактирование помещения.
- Удаление с подтверждением.
- Проверка прав администратора на сервере.

## US-10. Управление пользователями
Как администратор, я хочу управлять пользователями, чтобы контролировать доступ к платформе.

Критерии приёмки:
- Просмотр списка пользователей.
- Изменение ролей.
- Блокировка пользователей.
- Проверка прав администратора на сервере.
