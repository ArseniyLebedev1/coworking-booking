# Дни 3–5: ядро платформы

Реализация основного функционала учебного проекта «Платформа бронирования переговорных и коворкингов».

## Реализовано

- PostgreSQL: 7 таблиц, Alembic 0001 и дополнительная миграция 0002 с PostgreSQL EXCLUDE для запрета пересечений подтверждённых бронирований.
- Начальные данные: 3 роли, 2 коворкинга, 3 помещения и 4 удобства.
- FastAPI: регистрация, вход, Argon2, JWT (30 минут), профиль, RBAC.
- CRUD локаций и помещений (изменение данных только администратором).
- Бронирования: создание, проверка занятости, список собственных броней, отмена, просмотр всех броней администратором.
- React/TypeScript/Vite: каталог, карточка помещения, формы входа/регистрации, личный кабинет и панель администратора.
- GitHub Actions: синтаксис и тесты Python, сборка frontend, интеграционные тесты с PostgreSQL и контейнерами.

## Как запустить

1. Создайте файл \`.env\` в корне на основе \`.env.example\` (не коммитьте \`.env\`).
2. Задайте \`JWT_SECRET_KEY\`: \`python -c "import secrets; print(secrets.token_urlsafe(48))"\`.
3. \`docker compose up --build -d\`.
4. Откройте http://localhost:5173 (frontend) и http://localhost:8000/docs (API).

Для проверки: \`docker compose ps\`, \`docker compose logs backend\`.

Новая регистрация выдаёт роль \`employee\`. Назначить \`admin\` можно только вручную в БД — публичного повышения прав нет.

## Ограничения

Не включены поиск, фильтрация, пагинация и загрузка файлов (этап дней 6–7). Расширенные методы API из предварительного OpenAPI (refresh/logout, восстановление пароля, CRUD удобств и статистика) пока не реализованы; фактические маршруты доступны в \`/docs\`. Перед production-развёртыванием потребуются TLS, управление секретами, ограничения запросов и настройки CORS.
